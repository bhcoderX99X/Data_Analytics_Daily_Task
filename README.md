# Data Analytics Daily Tasks 📊

Welcome to the **Data Analytics Daily Task** repository! This repository serves as a practical log and showcase of daily hands-on projects, exercises, and tasks covering the core stack of data analytics: Microsoft Excel, SQL, Python (NumPy & Matplotlib), and Power BI.

---

## 🛠️ Repository Structure & Daily Tasks

The tasks are structured day-by-day covering fundamental to advanced data concepts across different tools.

### 📗 Phase 1: Microsoft Excel Fundamentals & Dashboards
* **Day 01:** `Day-> 1 -Excel-Basics.xlsx` — Introduction to Excel grid, basics, and navigation.
* **Day 02:** `Day-> 2 Excel-Tables.xlsx` — Working with dynamic Excel Tables and structured references.
* **Day 03:** `Day-> 3 Excel-Functions-Basics.xlsx` — Basic mathematical and logical functions.
* **Day 04:** `Day-> 4 Conditional-Functions.xlsx` — Conditional logic using IF, AND, OR functions.
* **Day 05:** `Day-> 5 Conditional-Calculation.xlsx` — Aggregations with SUMIF, COUNTIF, and AVERAGEIF.
* **Day 06:** `Day-> 6 Lookup-Functions.xlsx` — Data retrieval with VLOOKUP, XLOOKUP, and INDEX/MATCH.
* **Day 07:** `Day-> 7 Text-Functions.xlsx` — Text cleaning and manipulation (LEFT, RIGHT, MID, CONCAT).
* **Day 08:** `Day-> 8 Text-Functions.xlsx` — Advanced string manipulations and formatting.
* **Day 09:** `Day-> 9 Date-Time-Functions.xlsx` — Date arithmetic and timeline functions.
* **Day 10:** `Day-> 10 Pivot-Tables.xlsx` — Building dynamic Pivot Tables.
* **Day 11:** `Day-> 11 Pivot-Analysis.xlsx` — Deep-dive data analysis using Pivot summary views.
* **Day 12:** `Day-> 12 Pivot Charts.xlsx` — Data visualization using Excel Pivot Charts.
* **Day 13:** `Day->13 Sales_Dashboard_Pivot_Charts.xlsx` — End-to-end Sales Performance Dashboard.
* **Day 14:** `Day-> 14 Spotify_Dashboard.xlsx` — Interactive Spotify Music Analysis Dashboard.

---

### 🗄️ Phase 2: Database Management & SQL
